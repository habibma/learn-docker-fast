# learn-docker-fast

Learn the Docker fundamentals you actually need
to start building multi-container applications.

## Course goal

Understand Docker by building your knowledge
from Linux processes to Docker Compose.

## Course

1. Linux Processes
2. Docker Fundamentals
3. Dockerfiles
4. Networking
5. Volumes
6. Services Without Docker
7. Docker Compose
8. Mini Project

## Who is this for?

Developers who want to understand Docker quickly
through hands-on practice rather than a long theoretical course.

## Prerequisites

Basic Linux command-line knowledge is recommended.

## Philosophy

Don't memorize Docker commands.

Understand what Docker is doing.
