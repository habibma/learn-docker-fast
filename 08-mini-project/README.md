# Final Project
Are you ready to build a complete application with multiple services?

## Introduce
In this mini-project, you will build a complete web application using Docker and Docker Compose. The application will consist of multiple services, including a web server, a database, and a PHP application.

## The Goal
The goal of this mini-project is to give you hands-on experience with Docker and Docker Compose by building a real-world application. You will learn how to define and manage multiple services, configure networking and volumes, and troubleshoot issues that may arise during development.


## What You Will Build
You will build a simple web application that allows users to submit and view messages. The application will consist of the following services:
- A web server (NGINX) that serves static HTML pages and handles incoming requests.
- A PHP application (PHP-FPM) that processes user input and interacts with the database.
- A database (MariaDB) that stores user messages.


## Docker concepts being practiced
- Dockerfile
- Docker Compose
- Multi-container applications
- Networking
- Volumes
- Environment variables

## prerequisites
- Basic knowledge of Docker and Docker Compose
- Familiarity with HTML, CSS, and PHP
- Understanding of web development concepts
