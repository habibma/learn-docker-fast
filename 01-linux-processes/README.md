# Linux Processes

Before we understand containers, It's important to understand how Linux runs programs. This section will cover the basics of Linux processes and process IDs

## What we'll learn

In this section, we'll build our understanding step by step:

1. **Processes** — What a process is and how Linux runs programs.
2. **Process IDs** — How Linux identifies and manages processes.


## The goal

You don't need to become a Linux kernel expert. You just need to understand enough to answer the question:

> What is happening underneath a Docker container?

Once you can answer that, Docker stops looking like magic.
