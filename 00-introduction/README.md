# Introduction

Before we start using Docker, let's understand **why Docker exists**.

Docker is often introduced as a collection of commands:

```bash
docker run
docker build
docker exec
docker compose
```

But learning commands is not the goal of this course.

The goal is to understand the problems Docker was created to solve and the Linux concepts that make containers possible.

## What we'll cover

In this section, we'll follow the story that leads to Docker:

- **Before Docker** — How applications were traditionally deployed.
- **The "works on my machine" problem** — Why software behaved differently across environments.
- **Virtual machines** — How virtualization helped and what limitations remained.
- **Linux isolation** — The operating-system features that made containers possible.
- **Containers** — The idea behind lightweight process isolation.
- **Docker** — How Docker made working with containers practical and accessible.

By the end of this section, you should have a clear answer to:

> **Why do we need Docker?**
