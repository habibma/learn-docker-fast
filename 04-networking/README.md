# How Do Containers Communicate?
This is where we are diving to the networking aspect of Docker. Containers can communicate with each other and with the outside world through various networking mechanisms. Understanding these concepts is crucial for building complex applications that consist of multiple containers.


The key mistake we want to avoid is thinking:

> All containers live on one shared computer, so they can reach the other containers.

NO!!!
